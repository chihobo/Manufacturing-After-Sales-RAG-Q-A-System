# A-160 注塑机操作手册（V3.0）

本手册适用于 A-160 型卧式注塑机的操作、点检与日常保养。V3.0 版经客户技术负责人签字确认，为当前有效版本；V2.1 及以前版本已归档，仅存量老设备备查使用。

本版主要变更：
- 技术参数表按确认清单统一修订，液压系统压力上限确认为 16MPa。
- 增加伺服液压系统日常点检项目。
- 重写开机 / 关机操作流程，细化射台与锁模确认步骤。

<!-- page: 86 -->
# 安全注意事项

1. 本设备液压系统为高压系统，作业前必须确认系统压力已卸放，严禁带压拆卸液压管路。
2. 安全门未关闭时设备不得进行锁模与射胶动作，严禁短接安全门行程开关。
3. 液压系统压力上限为安全相关参数，任何人员不得擅自调高系统溢流阀设定值。
4. 更换模具、清理射嘴或进入动定模之间作业时，必须按下急停按钮并挂警示牌。
5. 液压油温度超过规定范围时设备将报警，应立即停机查明原因，不得屏蔽温度保护继续运行。

# 开机操作流程

1. 合上车间配电柜内本机断路器，确认三相电压在 380V±10% 范围内。
2. 打开设备主电源开关，操作面板自检通过后进入待机画面。
3. 检查液压油箱油位，油位应处于油标上下限之间；不足时补充 ISO VG 46 抗磨液压油。
4. 启动油泵电机，空载运行 3~5 分钟，观察系统压力表，空载压力应低于 2MPa。
5. 开启料筒加热，按工艺卡设定各段温度，待实际温度到达设定值后恒温 15 分钟。
6. 手动方式进行射胶、熔胶、松退各动作试车，确认射台进退平稳、无异常声响。
7. 低压低速手动锁模一次，确认模具安装状态与安全门联锁有效。
8. 切换至半自动模式试生产 3~5 模，确认制品外观与重量合格后转入自动生产。

# 关机操作流程

1. 停止自动循环，将操作模式切换至手动。
2. 清空料筒内余料：连续射胶至射嘴无料流出，必要时换用清洗料置换。
3. 射台整体后退，使射嘴脱离模具浇口套。
4. 将模具开至开模终止位置，取出模内制品与流道。
5. 关闭料筒各段加热，待料筒温度降至 80℃ 以下方可停止油泵。
6. 按下油泵停止按钮，确认系统压力表指针回落至零。
7. 关闭设备主电源开关，清理机台卫生并填写交接班记录。

# 液压系统日常检查

1. 每班开机前检查油箱油位，油位低于下限时禁止启动油泵。
2. 每班观察液压油温度，正常工作油温为 30~55℃；超过 60℃ 时检查冷却器水路是否畅通。
3. 每周检查系统压力表读数，生产状态下系统压力不得超过 16MPa 上限。
4. 每周检查液压管路接头与油缸密封处有无渗漏，发现渗油立即紧固或更换密封件。
5. 每月取样检查液压油清洁度与黏度，油液出现乳化、发黑或异味时整体换油。
6. 每半年更换回油滤芯与吸油滤芯，更换时同步清理油箱底部沉积物。

# 润滑与保养

1. 锁模机构哥林柱、调模丝杠采用集中润滑，每班检查润滑油箱油位与分配器动作。
2. 射胶导轨与射台移动导轨每班加注锂基润滑脂一次。
3. 顶出机构导杆每周涂抹润滑脂，防止顶针卡滞造成顶出不平衡。
4. 伺服电机与齿轮泵联轴器每季度检查对中与弹性体磨损情况。

# 常见报警初步处置

1. 油温异常报警：先检查冷却器进出水温差，再检查油温传感器接线，详见《故障代码表》对应代码。
2. 润滑压力不足报警：检查润滑油箱油位、油泵电机与分配器堵塞情况。
3. 安全门报警：检查前后安全门行程开关位置与门轮滑块磨损。
4. 报警信息中的故障代码务必与手册原件核对字样，严禁凭记忆处理。
