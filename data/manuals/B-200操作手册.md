# B-200 注塑机操作手册

本手册适用于 B-200 型卧式注塑机的操作、点检与日常保养。B-200 采用伺服节能液压系统，锁模机构为五支点双曲肘结构，适用于中大型精密制品生产。

<!-- page: 89 -->
# 安全注意事项

1. 液压系统压力上限为安全相关参数，严禁擅自调高溢流阀或比例压力阀设定。
2. 液压管路检修前必须卸放系统压力，确认压力表归零后方可拆卸。
3. 安全门、前后安全挡板与急停按钮构成联锁保护，严禁任何形式的短接与屏蔽。
4. 油温、油位、润滑报警触发后应立即停机处理，不得强制复位继续运行。

<!-- page: 90 -->
# 主要结构概述

B-200 主要由锁模机构、射胶机构、液压系统、电气控制系统四部分组成。锁模机构为五支点双曲肘结构，锁模力 2000kN；射胶机构采用双射胶油缸对称布置，射胶过程螺杆受力均衡；液压系统由伺服电机直驱内啮合齿轮泵供油，按动作需求实时调速，节能效果明显。

# 操作面板说明

1. 主画面显示锁模、射胶、顶出各段实时位置与压力曲线。
2. 参数画面按工艺权限分级开放，系统压力相关参数仅设备主管以上权限可修改。
3. 报警画面记录最近 200 条报警，含故障代码、发生时间与复位状态，处理故障时应先翻阅报警记录。
4. 点检画面提供液压系统日常点检清单，每班完成后由当班组长电子签名确认。

# 操作流程

开机流程：
1. 合上配电柜断路器，确认三相电压 380V±10%。
2. 打开主电源，面板自检通过后检查液压油位与油温。
3. 启动油泵空载运行 3~5 分钟，空载压力应低于 2MPa。
4. 按工艺卡设定料筒各段温度，恒温 15 分钟后手动试射胶、熔胶动作。
5. 手动低压锁模确认模具状态，切换半自动试产 3~5 模合格后转自动。

关机流程：
1. 停止自动循环并切至手动，射空料筒余料。
2. 射台后退脱离浇口套，模具开至终止位置并取出制品。
3. 关闭料筒加热，料筒降至 80℃ 以下后停油泵。
4. 确认系统压力归零，关闭主电源并填写交接班记录。

# 液压系统异响排查

液压系统运行中出现异响（尖叫、敲击、嗡鸣声异常增大）时，按以下原因与步骤排查：

| 异响原因 | 判别特征 | 处理步骤 |
| --- | --- | --- |
| 吸油滤清器堵塞 | 油泵吸空尖叫声，油温上升加快 | 停机后拆检吸油滤芯，堵塞严重时更换；同步检查油箱油位 |
| 液压油中混入空气 | 压力表指针抖动，油液呈乳白色 | 检查吸油管接头密封，排尽管路空气；乳化油液整体更换 |
| 油泵磨损或损坏 | 随转速升高嗡鸣加剧，输出压力不足 | 测量油泵容积效率，效率低于 85% 时更换齿轮泵 |
| 溢流阀阀芯卡滞 | 高压段出现高频啸叫 | 拆解清洗溢流阀阀芯与阻尼孔，磨损严重时更换阀芯组件 |
| 联轴器对中不良或弹性体破损 | 周期性敲击声，电机与泵同轴度超差 | 重新对中联轴器，更换破损弹性体 |
| 系统压力设定超限 | 满载动作时异响并伴随油温升高 | 核对系统压力设定，恢复至 17.5MPa 上限以内 |

排查注意事项：异响排查必须在卸压状态下拆检任何液压元件；更换元件后先空载低速运行确认无异响再带载生产。

# 液压系统日常检查

1. 每班检查油箱油位与油温，正常油温 30~55℃，超过 60℃ 检查冷却系统。
2. 每班观察系统压力表，生产压力不得超过 17.5MPa 上限。
3. 每周检查管路接头与油缸密封渗漏情况，重点检查曲肘机构下方接头。
4. 每月取样检测油液清洁度与黏度，必要时过滤或换油。
5. 每半年更换吸油与回油滤芯，并清理油箱沉积物。
