# C-320 注塑机操作手册

本手册适用于 C-320 型大型卧式注塑机的操作、点检与日常保养。C-320 面向大型厚壁制品生产，锁模机构为直压式四柱结构，液压系统采用双泵合流设计，调试与检修须由持证设备人员执行。

<!-- page: 101 -->
# 安全注意事项

1. 本机液压系统压力上限高于中小型机种，任何压力调整必须双人复核并记录。
2. 模具吊装必须使用额定载荷足够的行车与吊具，模具就位后方可拆卸吊环。
3. 进入动定模之间作业前，必须落安全撑杆并按下急停按钮。
4. 高压蓄能器检修前必须先卸放氮气压力，严禁带压拆解。

# 开机操作流程

1. 合上配电柜断路器，确认三相电压 380V±10%，冷却水压力不低于 0.2MPa。
2. 打开主电源，面板自检通过后检查液压油位、油温与蓄能器压力指示。
3. 启动油泵空载运行 5 分钟，空载压力应低于 2.5MPa，双泵切换无冲击声。
4. 按工艺卡设定料筒各段温度，恒温 20 分钟后手动试射胶与熔胶动作。
5. 手动低压低速锁模一次，确认模具、安全撑杆与安全门联锁状态。
6. 半自动试产 3~5 模，确认制品重量与外观合格后转自动生产。

# 关机操作流程

1. 停止自动循环，切换至手动模式，射空料筒余料。
2. 射台后退脱离模具浇口套，模具开至终止位置取出制品。
3. 关闭料筒各段加热，料筒温度降至 80℃ 以下后停止油泵。
4. 卸放蓄能器压力，确认系统压力表归零。
5. 关闭主电源与冷却水阀门，清理机台并填写交接班记录。

# 液压系统日常检查

1. 每班检查油箱油位与油温，正常油温 30~55℃，超过 60℃ 检查冷却器与水路。
2. 每班观察系统压力表，生产压力不得超过 21MPa 上限。
3. 每班检查蓄能器压力指示，低于规定值时由设备人员补充氮气。
4. 每周检查双泵合流切换阀动作与管路接头渗漏情况。
5. 每月取样检测油液清洁度，清洁度劣化时使用滤油机循环过滤。
6. 每半年更换吸油与回油滤芯，清理油箱并检查油液黏度。
